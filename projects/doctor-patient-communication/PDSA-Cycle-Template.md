# PDSA Cycle Documentation Template

## Improving Doctor–Patient Communication Through Patient Voice

**Project:** Patient Voice for Quality Care  
**Setting:** Hospital Outpatient Department (OPD)  
**Methodology:** Model for Improvement — Plan–Do–Study–Act (PDSA)  
**Document Status:** Reusable Template — Not a Completed Improvement Cycle

---

## 1. Purpose

This template supports healthcare quality improvement teams in planning, conducting, evaluating, and documenting small-scale tests of change to improve doctor–patient communication.

The template should be completed separately for each PDSA cycle. Findings from one cycle should inform the next.

## 10. Important Notes

This template is intended for quality improvement documentation and does not, by itself, demonstrate intervention effectiveness.

Results should be interpreted in relation to sample size, data quality, implementation context, and possible confounding factors.

Do not upload identifiable patient data, confidential clinical records, or sensitive staff information to a public GitHub repository.
